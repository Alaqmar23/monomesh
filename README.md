# Monomesh - 3D Generation Platform

This is a stateless, serverless full-stack application that transforms single images into 3D meshes using the InstantMesh AI model.

## Tech Stack
* **Frontend:** React, TypeScript, TailwindCSS, Three.js (deployed on Vercel)
* **Backend GPU Worker:** Python, FastAPI, PyTorch (deployed on Modal)

## Architecture
The frontend sends image uploads to a serverless Modal instance via HTTP POST (`/submit`). The Modal instance handles 3D model generation on a T4 GPU and returns an ID. The frontend polls `/status/{job_id}` until the reconstruction finishes, then downloads the `.glb` file natively in the browser.

## Deployment Instructions

### 1. Backend (Modal)
Ensure you have Modal installed and authenticated:
```bash
pip install modal
modal token new
modal deploy modal_server.py
```

### 2. Frontend (Vercel)
Upload the `frontend/` folder to Vercel. 
Ensure you add the following Environment Variable in Vercel before deploying:
* `VITE_MODAL_URL`: The URL generated by the `modal deploy` command.
